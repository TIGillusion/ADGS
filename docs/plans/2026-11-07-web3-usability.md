# Web3 工作台视觉与交互优化

目标：在现有项目、会话、Hermes 和图谱数据模型上，提高阅读与操作体验。保持浅色、深色切换；不改变任务调度和模型配置。

1. 工作台：可收起项目导航，窄屏抽屉导航，按需显示项目资料，保存界面偏好；保留搜索、归档、创建时间排序。
2. 阅读：扩大正文列宽，提高中文排版和浅色对比度；产出物显示文件名，折叠完整路径，支持复制和展开列表。
3. 输入：多行自适应高度，中文输入法回车保护，命令选择保存草稿；明确默认排队与引导时机，准确显示 CEO 阶段。
4. 观测：执行详情匹配主题，保留深色终端；图谱使用可读的标题与操作提示。
5. 验证：交互单元测试、完整前端测试和构建；真实历史会话只读检查浅色、深色、桌面与窄屏，核对横向溢出和导航、抽屉操作。保存截图与结果。

实现授权来自用户本轮请求；直接在当前工作区实施。现有 Git 提交 762b873 和完整系统备份可用于回滚。本轮不发送任务，不修改研究数据。

用户已确认浅色与深色都保留、可切换。浏览器首轮检查发现展开文件列表后，回到底部按钮占据文档高度，出现跟随状态切换抖动；已将该浮动按钮改为零高度容器，真实点击展开与收起已通过。窄屏检查还发现通用首子元素样式误把用户气泡压窄，已将尺寸限制仅用于头像。

完成：节点列表与概览同步主题和窄屏样式，节点可用键盘打开；执行事件支持中文搜索并显示关键事件数量。211 项前端单元测试、构建、6 项浏览器回归通过。真实历史会话在 1600、1280、768、390px 下完成只读检查；53 个原有历史会话校验一致。详情见 `docs/验证_Web3交互优化_20261107.md`。
