# 发布审计工作台真实系统验收

目标：新隔离项目真实运行 CEO→协调负责人→六个并行模块→集成→独立验收，测试最新部署的常驻 Hermes 与 Web3。只依据文件、原生历史、API 和实际浏览器行为验收，不以模型自述为准。

1. 检查真实服务和空闲状态，保存原会话及配置摘要；建立独立工作区、固定接口与只读样例。
2. 提交六模块复杂任务，观察最大五个工作名额、至少一个排队、父节点等待及日志输出。CEO/负责人只协调，叶子完成实现。
3. 在 Web3 默认排队输入长引导，编辑后点击引导；另放普通队列消息。验证完整且单次消费、已派批次先完成、普通队列最后处理。
4. 原实例补工，确认 PID/Agent/session、轮次与图谱对应。独立复核算法、陌生输入、特殊名称、实际 CSV 下载、375px/桌面、深浅主题。
5. 有缺陷则最小修复，运行针对性回归并重新走实际失败路径。只在需要加载修复且已安全收尾时部署；保留原历史与已通过产物。
6. 业务最终完成、普通队列清空后，核对数据保留、浏览器重开与日志，备份证据并提交 Git。必要服务重启另比较前后持久状态。

完成界限：上述覆盖通过，发现的可复现问题闭环，服务可用。测试不能证明所有未来任务永不出错。Worker 使用现有自建模型，CEO 使用现有付费配置，不更改全局模型。
