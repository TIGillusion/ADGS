# Web3 A2A 图谱修复计划

目标：小点使用与树节点一致的世界坐标；同一参与方只有一个位置；多次委派分别可点击。

方案比较：实例周围散点无法保证多参与方不重叠；将参与方插入 CEO 树会改变任务层级语义；采用树边界外的有序外圈，不修改后端任务模型。

1. 从只读事件库提取真实 A2A 会话事件，在隔离测试页回放，不向运行中页面注入数据。
2. graphCanvas.ts：统一自动锚点计算、绘制及命中；外圈按 ID 排序；使用 store 手动偏移实现跨视图保留；整理清空偏移；fit 包含小点。
3. 曲线：双向委派统一法向，多边按屏幕间距分离；沿曲线线段命中；箭头落在形状边界。
4. 增加坐标不随平移变化、共享锚点、拖拽/整理、双向多边和曲线中段命中的回归测试。
5. 运行 web3 测试、类型检查和构建；用真实历史回放检查画面，记录验证边界。保留已有未提交工作，不提交，不重启运行任务。

## 实施与验证结果

- 修复视口中心参与世界坐标、自动锚点无法命中、同一参与方多位置、反向边重叠、曲线采样命中空洞及形状投影误作边界的问题。
- 外圈按 ID 排序，并整体朝关联实例旋转；绘制与命中复用同一锚点；手动位置进入 graphManual，切视图保留，整理与恢复原始布局一起处理。没有增加刷新后的磁盘布局持久化。
- 限制 GraphView 的全局委派档案补齐范围，避免跨会话混入。历史 API 从持久事件库读取 graph/node/a2a 事件，增加结构事件的稀疏索引；store 同步恢复交互时间线。移除委派边 50/60 条和单委派时间线 100 条的静默丢弃。
- 前端 163 项测试通过（新增 6 项 Canvas 回归、1 项历史时间线回归）；构建及类型检查通过。后端 session replay / mesh A2A / console log 共 25 项通过。
- 通过只读导出的 280 条真实结构事件，分别回放 a2a-live-test（12 节点，1 外部锚点，3 条委派边）和 mijia_lab（50 节点，5 条委派边）。测试平移、锚点拖动、树状/行星整理及每条边详情；截图位于 web3/test/.a2a-*-tree.png 和 .a2a-*-radial.png。
- 重现方法：仓库根目录运行 python web3/e2e/export-a2a-replay.py；在 web3 启动 E2E_PORT=8107 的 node e2e/mock-server.mjs，再运行 node e2e/a2a-replay.mjs。浏览器缓存目录可用 PLAYWRIGHT_BROWSERS_PATH 指定；测试不会向实际 runtime 注入事件。
- 实际 8021 已提供新 dist；检查时 busy=true，未重启。后端历史读取变更尚未在该进程生效，需要任务结束后的正常重启。

交接中的 worker 工具逐步详情、启动 bat 全链路、新 profile MCP 接线与长期并发稳定性未在本轮宣告完成；本轮完成范围是 web3 图谱及其历史委派读取链路。
