# 任务适配优先与递归委派

用户要求：困难任务继续拆分给其他节点或同一角色的新实例；相关专长优先，无匹配专长时通用节点明显优于不相关的高分节点。

## 决策

- 统一 CEO 路由与 A2A 目录的适配规则。提取当前任务、需求及验收目标再向量化，避免长背景和通用工作区条款挤掉真正目标。
- 相似度权重由 1.5 提高到 3.0，成功率权重从 0.5 降为 0.2；成功率影响有界，累计分不直接决定任务分配。
- 尚未分化的通用描述作为中性能力基线；无专长超过基线时优先通用候选。明确匹配的专长节点进入前列；探索只在适配相近的短名单内进行。中性基线是调度策略，不代表模型输出的相似概率。
- 温度采样使用分数的对数，避免幂次提高后绝对值变小、softmax 反而接近平均随机。输出原始相关度、有效适配、通用标识和探索加成便于检查。
- 合并模式任务书在开工前明确要求复杂度与分工判断，困难可拆任务默认拆分；相同 node_id 可以创建新 execution/session，共享技能记忆，不共享本次对话。简单任务仍直接完成，深度到顶后停止继续拆分。
- 上级 wait 子任务时临时让出执行名额，返回前重新取得；名额由执行实例持有，取消与结束不会重复释放。委派使用有上限的独立等待线程，避免固定池中父任务等子任务造成饥饿；实际执行仍受全局并发限制。

```mermaid
flowchart LR
  A[当前子任务目标] --> B[统一适配排序]
  B --> C[匹配专长 / 通用兜底]
  C --> D[节点判断复杂度与分工]
  D --> E[简单任务直接完成]
  D --> F[其他角色或同角色新实例]
  F --> G[等待时让出执行名额]
  G --> H[复核与整合汇报]
```

## 验证与生效

- 单测：专长胜出、通用兜底、高累计分不越级、低成功率不归零、冷启动、温度和降级；CEO/A2A 一致；同角色新实例与递归预算。
- 无模型调用的并发回归：单名额父子递归可结束，嵌套超过旧线程池大小仍完成，取消/超时后名额正确，委派提交失败不会留下永久 running。
- 本地 BGE 真实向量对照和只读真实种群排名检查；不向模型提交真实任务。
- 当前真实服务有运行任务，不重启、不打断在途工作。配置可通过现有热设置接口更新；代码与任务书变化需服务重新加载，不能声称已改变运行中 worker 的提示。

## 验证结果与部署状态

- 148 项相关后端测试及 5 个子测试通过；最终补充的串行脑提示、并发等待、非阻塞查询及任务书标题兼容后，23 项路由/委派专项测试通过。测试覆盖真实 mesh wait 与父执行名额交接、同角色新执行 ID、取消、超时和启动失败，不调用真实 LLM。
- 本地 BGE 真实向量的五组对照全部符合预期：前端、数论、设备、小说分别选择匹配专家；无烹饪专家时选择通用节点。对照中故意令正确专家历史成功率更低，旧公式五组均选错，新规则选中预期候选。
- 只读检查实际 57 个活动节点，其中 9 个尚未分化的通用节点；新短名单能在缺少匹配专长时把这些节点排到前列。完整诊断保存在 `.adgs_runtime/router-relevance-20261104.json`。阈值为本次调度基线，不把余弦值解释为相似概率；模型说明见 [BGE model card](https://huggingface.co/BAAI/bge-small-zh-v1.5#frequently-asked-questions)。
- 已通过现有热设置接口将实际服务相关性权重设为 3.0、历史质量权重设为 0.2，其余运行参数保留；原值备份在 `.adgs_runtime/tuning-before-relevance-20261104.json`。Web3 参数说明已更新并构建通过。
- 当前会话仍在运行，因此没有重启宿主。完整的候选筛选、递归委派提示和名额交接代码需宿主重新加载后生效；在途 worker 的提示和旧运行代码未被替换。
