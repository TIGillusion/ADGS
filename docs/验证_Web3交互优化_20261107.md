# Web3 工作台优化验收

日期：2026-11-07。范围仅为 `web3/` 前端及测试，不改变后端调度、模型配置或任务执行逻辑。

## 已实现

- 保留浅色、深色切换与选择记忆；调整浅色功能色、图谱与概览数字的对比度，执行详情跟随当前主题。
- 项目导航支持收起与偏好保存，窄屏使用抽屉导航；保留创建时间排序、搜索、归档、忙碌标签。项目分组折叠状态可保存，资料栏按需打开。
- 正文列宽与中文排版优化；产出物显示文件名和所在目录，默认四项，可展开全部、查看与复制原始完整路径。
- 输入框随多行内容及宽度变化增高；保护中文输入法确认回车，命令选择保存草稿；明确默认排队与引导时机，按实际 CEO 阶段显示等待状态。
- 执行事件显示关键事件数量，隐藏高频状态与会话消息，支持中文阶段名称搜索；无匹配时明确提示。原始事件仍可展开查看。
- 图谱展示会话标题与操作说明；节点列表在窄屏按卡片分行，节点名称可用键盘打开。
